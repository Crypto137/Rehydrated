# Version Differences

This file documents the differences between the vanilla pre-expansion versions of Diablo III and the more modern releases, as well as the differences between 1.0.8.16603 (the final PC build) and C1.0.0.17339 (the initial Xbox 360 build that this recompilation is based on).

## Vanilla Differences

- There is no Adventure mode, Bounties, or Nephalem Rifts. All farming is done via the Campaign mode.

- The Campaign is split into Normal/Nightmare/Hell/Inferno difficulty modes, similarly to Normal/Nightmare/Hell in Diablo II.

- There is no level scaling for monsters.

- Instead of Normal/Hard/Expert/Master/Torment difficulty settings, there are ten Monster Power levels that function similarly to the `/players` command in Diablo II.

- Hero level cap is 60.

- There are three passive skill slots instead of four.

- Many skills have different runes, and there are passive skills that were removed or reworked in later versions (e.g. Wizard's Critical Mass).

- Paragon levels are capped at 100, and each hero has their own Paragon level.

- There are no Paragon points to allocate. Heroes automatically gain attribute bonuses similarly to 1-60, as well a Magic Find bonus, when they reach a new Paragon level.

- Magic Find exists as a stat on gear.

- There is no smart loot and no separation between Primary and Secondary affixes.

- Legendary and Set items are a lot less powerful, and many of the best items are well rolled Rares.

- Legendary specific affixes are a lot less impactful.

- All items can be traded without limitations.

- The Mystic crafter NPC is disabled.

- There is no Kanai's Cube.

## Xbox 360 Differences

- Monster Power levels were renamed to Difficulty with 8 options (Easy/Medium/Hard/Master 1-5).

- Different health potion tiers were consolidated into a single health potion that heals for a percentage amount.

- Additional tiers of affixes were added, raising the ceiling of equipment power.

- New affixes were added for some of the Legendary items.

- Legendaries can roll as higher level versions when dropped by higher level monsters.

- A dodge roll action was added for all classes to make it easier to hit-and-run on a controller.

- Some skill animations and VFX were adjusted.
